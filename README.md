# Гран-Канария — карманный путеводитель (Бедекер-стиль)

Репринт в стиле немецких брошюр Бедекера, на русском языке, с акцентом на
природу и пешеходные маршруты. Сборка — XeLaTeX.

## Сборка

```
make
```

Требования: `texlive-xetex`, `texlive-lang-cyrillic`, `texlive-latex-extra`,
`texlive-fonts-extra`, `texlive-pictures`, `latexmk`. Результат — `main.pdf`.

## Структура

- `main.tex` — каркас документа
- `preamble/` — пакеты, цвета, Бедекер-макросы
- `chapters/` — текст по главам
- `maps/` — схематические карты троп (TikZ)
